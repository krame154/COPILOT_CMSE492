# COPILOT_CMSE492

## Project Title
Is there a correlation between fast food unhealthiness and popularity?

## Setup Instructions
1. Clone the repository using `git clone <repository-url>`.
2. Navigate to the project directory.
3. Install the required packages listed in `requirements.txt`.

## Quick Start Guide
1. Open Jupyter Notebook using `jupyter notebook` command.
2. Open `notebooks/01_exploratory_analysis.ipynb` to start exploration.
