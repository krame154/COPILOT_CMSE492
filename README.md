# Overview

This dataset comprises 515 menu items from 8 major fast food chains. Each menu item is evaluated across 17 different nutritional categories, providing a comprehensive understanding of its nutritional profile. Additionally, the dataset includes sales data that sheds light on the popularity of these items.

### Unhealthy Score Calculation
The dataset features a calculated unhealthy score for each menu item, offering insights into the health implications of consuming these fast food options.

### Research Question
The primary research question addressed is: What is the correlation between fast food unhealthiness and popularity? This question seeks to explore how the healthiness of menu items relates to their sales figures and consumer popularity.
